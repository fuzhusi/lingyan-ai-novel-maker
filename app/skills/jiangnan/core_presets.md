# 阶段与配置 Preset

使用时只选一个主 preset。

| Preset | 适用场景 | 声音 | 重点 | 失败警报 |
|---|---|---|---|---|
| P1 校园 / 温暖微苦 | 校园、青春回望、普通人错过 | 第三人称或温和回望 | 群像余温、小物承重、段尾回疼 | 写成纯怀旧散文 |
| P1-P2 武侠 | 小门派、个体英雄、江湖悲剧 | 可读白话为主，少量文白 | 仪式化动作、信念成本 | 伪古风堆辞 |
| P2 史诗 | 国家、部族、迁徙、战争 | 史官距离，结构性半文白 | 物仪式化、单层史诗情感 | 加现代吐槽 |
| P3 都市热线 | 城市、暗恋、延后、日常抵抗 | 贴近第一人称，可轻吐槽 | 暗恋悬置、文本/物延后 | 直接告白或命运召唤 |
| P3 都市冷线 | 谍战、政治、系统压力 | 冷叙事，档案感 | 棋盘式对话、现实压力 | 无情无味 |
| P4 少年被卷入 | 普通少年误入大系统 | 防御性口语到静默 | 反高潮被选中、世界压力进入 | 写成龙族开场 |
| P5 情感最大化 | 长日常后反向照亮 | 多声部，糖衣长铺 | 长糖后苦、受限表达 | 只写甜 |
| P6 冷寂 / 不在 | 缺席、记录、删除、无人记得 | 减法，低糖 | 空白即存在、物证替代 | 写成直白悼词 |
| P6 商业奇幻 | 机械、王权、兄弟、战争推进 | 多 POV，设定可见 | 机械/物人格化、盟约 | 写成龙族 IV 冷消失 |
| 根系 / 神话支线 | 起源、古老承诺、神话结构 | 根系叙述，仪式感 | 神话落到人的代价 | 只堆宏大设定 |

## 成本焦点

| Preset | 成本要落在哪里 |
|---|---|
| P1 校园 / 温暖微苦 | 错过、沉默、现实生活安排、普通人的迟到选择。 |
| P3 都市热线 | 回复/不回复带来的工作记录、关系后果、现实身份变化。 |
| P4 少年被卷入 | 被选中不是荣耀；确认意味着家庭安排、县城生活、未来路径被改写。 |
| P6 商业奇幻 | 阵营、权力、阶层、兄弟关系都要付费；机械选择要改变政治或身份位置。 |

## 选择规则

- 现代校园优先 P1，不要用 P6 冷寂覆盖。
- 都市暗恋可用 P3 热线；吐槽必须服务遮蔽，不能失控。
- 史诗题材用 P2 或根系支线，不要套龙族青春腔。
- 商业奇幻用 P6 商业配置，不要误用龙族 IV 的“不在”。
- 如果题目要求“什么都有”，先拒绝直接融合，再选主 preset。
