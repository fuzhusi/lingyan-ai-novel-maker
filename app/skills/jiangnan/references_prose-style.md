# 页面笔法

这一页管“句子怎么动、段落怎么落、情绪怎么藏”。先从 `longzu-evolution.md` 选 preset，再用这里写页面。

## 一、核心原则

江南感不是装饰性悲伤，而是页面运动：

1. 先落低：普通动作、小物、日常问题、玩笑、具体空间。
2. 把高情绪藏在低语言下面。
3. 让物、身体、对话、节奏、空白承重。
4. 段尾往低处收，让痛慢半拍回来。

## 二、四个天生指纹

### 1. 物/动作替代心理

不要先写“他难过”。写：

- 他把桌面灰抹平。
- 她把没送出去的票夹回书里。
- 他反复点亮手机，又按灭。
- 一个人把门关上，手还扶着门把手。

判断：删掉心理词后，读者还能不能知道他疼。

### 2. 对话潜台词

表面说小事，底下是大事。

可用形式：

- 问作业，其实问你还记不记得我。
- 说“水还是你的”，其实是不敢说谢谢。
- 说“没事”，但动作已经把事暴露了。

不要让人物直接把核心情绪讲完。

### 3. 大题小作 / 小题大作

大题小作：城市要毁了，他先问便利店还开不开。

小题大作：一张值日表、一枚纽扣、一行铅笔字，承担十年、战争、离别或命运。

关键：小物不能只是道具，必须改变人物动作。

### 4. 段尾回疼

段尾不要总结大道理。用低、静、具体的事实收。

可用方式：

- 动作停住。
- 物还在。
- 名字没被叫出。
- 光线落在不该还存在的东西上。
- 人没有做那个原本应该做的动作。

## 三、句子运动

- 短句：冲击、决定、段尾、冷收。
- 中句：行动、对话、移动。
- 长句：回望、环境压迫、比喻升维。

不要全短。全短会像故作深沉。也不要全长。全长会散。

## 四、语言材料

每场只选一个底层材料，再加一个压力层。

- 校园：普通白话、同学口气、小动作。
- 都市热：自嘲、低语言、网络/职业/生活词。
- 都市冷：档案、制度、名单、机械流程。
- 史诗：半文白、史官距离、仪式物。
- 商业奇幻：设定词、机械/权力词，但必须让人承重。

## 五、比喻升维

结构：

小物 -> 大尺度 -> 回到人。

例如：

- 铅笔印不是“像宇宙一样”，而是：它先是灰，后是十年，最后落回指腹上的木刺。
- 巨钟不是只宏大，它要落回某个人不敢拉下的绳。

不回到人的代价，就不要升维。

## 六、空白和沉默

沉默不是留白符号，而是行动失败：

- 电话没拨出。
- 字没擦掉。
- 门没打开。
- 名字没念完。

空白要有物证支撑。

## 七、结尾

结尾要“落地 + 开口”。

落地：有一个具体动作或物。

开口：命运没有完全关上，读者还会在后面想。

不要大团圆，不要强行虐，不要解释主题。
