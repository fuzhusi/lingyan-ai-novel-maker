# 江南感写作

版本：v1.1.1，通用核心 + Codex 入口。

本文件是 Codex 可安装入口。真正的平台无关协议在 `core/`；不同 AI 的调用方式在 `adapters/`。

## 使用原则

- 目标是原创写作中的“江南感”，不是同人续写，也不是复制任何源作品。
- 先立人，再选声线；先定缺口，再动笔法；先让物和动作承重，再让读者自己疼。
- 始终输出原创文本，不使用源作品人物、组织、设定、专名、桥段、源近句式。
- 不摘录受版权小说原文，不把生成内容说成官方文本。

## Codex 调用流程

处理写作、改稿、诊断、大纲任务时：

1. 先读 `core/protocol.md`。
2. 需要选阶段/配置时读 `core/presets.md`。
3. 需要页面级笔法时读 `core/fingerprints.md`。
4. 交稿或测试前读 `core/evaluation.md`。
5. 需要平台调用或安装说明时读 `core/install-and-use.md`。

v1.1.1 小补丁：写作前必须确认“现实成本 / 为什么他会选择”。人物不只是被物件触动，还要在钱、身份、关系、工作、名誉、身体、机会或阵营上付出代价。

旧 `references/` 仍保留作为更细的内部参考：

- `references/prose-style.md`：页面写法细节。
- `references/longzu-evolution.md`：阶段/配置细表。
- `references/workflow.md`：写作、改稿、诊断流程。
- `references/protocol-cards.md`：缺口、门外、遮蔽、糖/苦等卡片。
- `references/evaluation-gates.md`：评分和失败模式。
- `references/safety-and-boundary.md`：原创与引用边界。

## 输出要求

- 写作：优先给正文；必要时附简短协议卡或自检。
- 改稿：保留用户题目和设定，不擅自换题。
- 诊断：指出坏在哪一轴：缺口、语域、preset、四指纹、遮蔽、糖/苦、原创安全。
- 不用“很像”“很有感觉”这类空话；必须指出具体页面机制。

## 硬性失败

出现以下问题，必须重写或修订：

- 只有雨、天台、青春、孤独、短句，没有人物缺口。
- 把 P5 长糖、P6 冷寂、九州史官、前传历史腔、P4 烂话揉成平均声线。
- 把龙族烂话当通用江南感。
- 把龙族 IV 的“不在”当全部后期江南。
- 用九州史官声写现代校园。
- 比喻升维后不回到人的代价。
- 直接喊出情绪，而不让物、动作、对话、节奏承担。
