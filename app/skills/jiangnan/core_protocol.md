# 江南感通用写作协议

本协议是平台无关核心。Codex、Claude、DeepSeek、通用 LLM 都应调用同一套核心，只更换入口提示。

## 0. 目标

在原创文本里调出一种江南式的笔法运动和情感姿态：青春回望、缺口人物、远处的温暖、迟到的疼、信念付费、宏大与微物之间的转换。

它不是：

- 龙族同人或官方续写。
- 九州、龙族、天之炽、此间等源作品的情节复刻。
- 依靠雨、天台、孤独、短句、悲剧道具堆出的表面仿写。

## 1. 边界

- 只写原创人物、原创地点、原创组织、原创设定。
- 不使用源作品专名、桥段、人物关系、源近措辞。
- 不摘录受版权小说原文。
- 解释规则时只说可复用机制。
- 如果任务要求混合多个阶段，先选主 preset，其它元素降级为背景或删掉。

## 2. 四维定调

写之前必须定四个轴：

1. **阶段轴**：P1 校园 / P1-P2 武侠 / P2 史诗 / P3 都市过渡 / P4 少年被卷入 / P5 情感最大化 / P6 冷寂或商业奇幻 / 根系神话。
2. **题材语域轴**：校园、武侠、史诗、都市热、都市冷线、根系神话、商业奇幻。
3. **配置轴**：温暖微苦、史诗距离、都市热线、都市冷线、情感最大化、冷寂不在、商业奇幻等。
4. **指纹深度轴**：四个天生指纹优先；两个后期系统化工具按需；阶段专属工具不能乱用。

## 3. 调用顺序

1. 确认任务：写新稿、改稿、诊断、大纲。
2. 建人物缺口：他缺什么，用什么假装不缺，站在哪扇门外。
3. 加现实成本：如果他选择回应、留下、离开、相信、确认、交出或隐瞒，会失去什么。
4. 选题材语域。
5. 选一个阶段/配置 preset。
6. 挂四个天生指纹。
7. 按需加两个后期系统化工具。
8. 写正文或修正文。
9. 用评分门检查。

## 4. 内部卡

写作前先填，不要完整暴露给读者：

```text
人物缺口：
伪装：
门外位置：
现实成本：
为什么仍然选择：
题材语域：
目标 preset：
糖：
苦：
小物：
结尾动作：
必须避免的误用：
```

## 5. 选择成本规则

江南感不能只靠“物件触动人物”。物件要把人物推到一个有成本的位置。

合格选择至少回答两问：

1. **不选会失去什么**：人、机会、尊严、旧承诺、离开的机会、被承认的可能。
2. **选择会付出什么**：钱、时间、身体、名誉、关系、工作风险、阵营身份、生存压力。

如果人物只是看见旧物、沉默、转身，但没有任何现实代价，文本会有感觉但不够硬。

成本不必写大，可以很小：

- 回复一条短信会留下审计记录。
- 按下确认会改变家庭对他的安排。
- 交出齿轮会被自己所在的人群视为背叛。
- 回到旧教室会错过一个普通但重要的现实安排。

成本要通过动作、物、对话、制度细节露出来，不要用议论文解释。

## 6. 非融合规则

- 不要把烂话当通用江南感。
- 不要把龙族 IV 的冷寂当全部后期江南。
- 不要把九州史官声用于现代校园。
- 不要把前传历史腔当普通都市声线。
- 不要把商业奇幻的设定推进当成青春回望。
- 不要平均混合多个阶段。

主 preset 只能有一个。其它元素必须降级为局部工具、背景噪声或直接删除。
