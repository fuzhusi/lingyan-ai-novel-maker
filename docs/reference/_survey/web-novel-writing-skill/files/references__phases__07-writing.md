> **阶段编号**: Phase 7 / 10
> **执行角色**: ✍️ 文学渲染师
> **触发条件**: Phase 6 完成，当前批次章节细纲已确定
> **阶段目标**: 基于Beat Sheet生成高质量正文，消除AI写作痕迹，呈现网文风格
> **输出产物**: `chapters/vol-XX/chapter-XXX.md` 正文文件（每章2000-4000字）

## 一、阶段概述

正文生成是整个流水线中最"看得见"的环节，但也是最容易出问题的环节。AI生成的文本有显著的"AI味"——如果不加以控制，读者一眼就能看出来。

本阶段的核心任务是：**在遵循细纲的前提下，生成"人味儿"十足的网文正文**。

**核心原则**：宁可多花时间在风格渲染上，也不要生成一篇"正确但无趣"的文章。

## 二、写前强制检查（5项必检）

在开始生成任何一章正文之前，AI **必须** 完成以下5项检查。这不是建议，而是强制流程：

> **⚠️ 特别注意：黄金三章特化**
> 如果当前要求撰写的是**第 1 章、第 2 章或第 3 章**，请**立即停止执行本文档**，转而严格遵守 `07a-golden-three.md` 中的特化写作指令！

```
【写前五检】

□ ① 设定核查
  → 打开 rules.md，确认本章涉及的设定规则
  → 确认主角当前境界/能力水平
  → 确认本章场景的地理/势力信息

□ ② 角色核查
  → 打开相关角色卡，确认五维人格DNA
  → 回顾说话风格和行为红线
  → 确认角色当前的情感状态（上一章发生了什么）

□ ③ 时间线核查
  → 确认本章的故事内时间
  → 确认与上一章的时间间隔
  → 确认同时段其他角色在做什么（如有多线叙事）

□ ④ 伏笔核查
  → 检查本章是否有需要回收的伏笔
  → 检查本章是否需要埋设新伏笔
  → 确认已知信息边界（角色此时知道/不知道什么）

□ ⑤ 细纲核查
  → 重读本章的Beat Sheet
  → 确认每个Beat的目标和情感方向
  → 确认章末钩子设计
```

## 三、网文正文写作规范

### 3.1 段落与排版

```
网文排版铁律：

✅ 短段落：每段不超过3-5行（手机阅读友好）
✅ 多分段：对话、动作、描写分段处理
✅ 留白感：适当使用空行增加阅读呼吸感
✅ 对话独占段：每个角色的对话独立成段

❌ 不要：连续超过5行不分段的大段文字
❌ 不要：连续超过3行的纯描写（没有动作/对话打断）
❌ 不要：一段内塞入多个角色的对话
```

### 3.2 对话写作要求

对话是网文的灵魂，好的对话能让角色活起来：

**基本要求**：
- **符合角色**：每个角色的对话应该一看就知道是谁说的
- **有信息量**：每句对话要么推进情节，要么揭示性格
- **自然流畅**：像真人说话，不要像在念稿子
- **适度简洁**：网文对话偏短，一般1-3句，除非是重要独白

**对话标签变化**：
```
常用标签轮替（避免一直用"说"）：

基础类：说、道、问、答、笑道、冷声道
情绪类：怒吼、低喃、叹息、嗤笑、沉声道
动作类：摆手道、点头道、皱眉道、转身道
省略类：直接用动作代替对话标签

示例对照：
❌ "你是谁？"他说。"我不认识你。"他又说。
✅ "你是谁？"他后退一步，手不自觉地按上了腰间的剑柄，"我不认识你。"
```

**对话风格对照表**（参考角色卡）：

| 角色类型 | 说话特点 | 示例 |
|---------|---------|------|
| 冷静型主角 | 简短、直接、少废话 | "没必要。" / "继续。" |
| 热血型配角 | 激动、感叹号多、口语化 | "冲啊兄弟！干他丫的！" |
| 老谋深算型 | 意味深长、暗示多、拐弯 | "年轻人，有些事……急不来的。" |
| 傲慢型反派 | 居高临下、嘲讽 | "就凭你？呵。" |
| 温柔型女主 | 关切、委婉、细腻 | "你的伤……还没好吧？" |

### 3.3 描写层次与节制

**环境描写**：
```
✅ 好的环境描写（有功能性）：
"月光从破碎的窗棂间漏进来，在满地碎瓦上画出一道道惨白的痕迹。
空气中弥漫着陈旧的血腥味，至少三天了。"
→ 传达信息：废墟、夜晚、曾有战斗/杀戮、时间推断

❌ 差的环境描写（纯堆砌）：
"美丽的月光洒在大地上，清风徐来，树叶沙沙作响，
远处的山峦连绵起伏，一切都那么美好和宁静。"
→ 什么信息都没传达，纯凑字数
```

**战斗描写**：
```
网文战斗三要素：
1. 动作清晰 — 读者能在脑中"看到"画面
2. 节奏变化 — 快慢交替，不是一路高速
3. 有策略性 — 不只是比谁拳头大

战斗描写节奏模板：
快速对攻（短句、动词密集）
→ 僵持/观察（中句、内心活动）
→ 关键决策（短暂减速、角色思考）
→ 决胜一击（最快节奏、最有力的句子）
→ 结果呈现（节奏骤降、环境描写收束）
```

### 3.4 通过句式控制节奏

```
紧张场景用短句：
"他退了一步。又一步。背后是悬崖。无路可退。"

平缓场景用长句：
"阳光从窗外慵懒地铺进来，照在桌上那杯已经凉了的茶水上，
泛起一层淡淡的光晕，像是某个被遗忘的午后的回忆。"

重要时刻用独立短句，甚至独立成段：
"他出手了。"

"就那么一瞬间的事。"

"然后——一切都变了。"
```

## 四、⚠️ 反AI模式清单（核心）

这是本阶段最重要的部分之一。以下列出的所有模式，在正文中 **必须避免**：

### 4.1 禁用词汇与短语

```
【🚫 绝对禁用词汇】

哲学废话类：
- "在这个世界上"
- "不禁让人想起"
- "仿佛在诉说着什么"
- "这一刻，时间仿佛静止了"
- "命运的齿轮开始转动"
- "在历史的长河中"

过度总结类：
- "总而言之"
- "综上所述"
- "不得不说"
- "值得一提的是"
- "毫无疑问"

情感过度类：
- "内心深处涌起一股难以名状的感觉"
- "复杂的情感在心中交织"
- "百感交集"（直接写具体是什么感受）
- "一种说不清道不明的情绪"

形容词堆砌类：
- "巨大的、恐怖的、令人窒息的压力"（选一个就够了）
- "美丽的、动人的、令人心醉的容颜"（别用三个形容词）
```

### 4.2 禁用句式结构

```
【🚫 禁用句式】

1. "随着XXX的XXX，XXX也XXX了" 万能开头
   ❌ "随着修炼的深入，他的实力也水涨船高"
   ✅ "又一个月过去了。当他再次凝聚灵力时，掌心的光芒明显比之前亮了三分。"

2. "他不知道的是，XXX" 上帝视角插话
   ❌ "他不知道的是，此时远处有一双眼睛正注视着他"
   ✅ （直接切换视角写那双眼睛，或者用环境暗示）

3. "如果XXX知道XXX的话，一定会XXX" 假设句式
   ❌ "如果他知道这块石头价值连城，一定会大吃一惊"
   ✅ 删掉。直接让后续情节自然揭露价值。

4. "XXX看着XXX，嘴角微微上扬" AI最爱
   ❌ "他看着远方，嘴角微微上扬，眼中闪过一丝精光"
   ✅ 换成具体的、有角色特色的表达

5. "不由得/不禁" 的过度使用
   ❌ "他不由得吃了一惊" / "她不禁皱起了眉头"
   ✅ 直接写反应："他猛地站起来" / "她的眉头拧在了一起"
```

### 4.3 禁用叙事模式

```
【🚫 禁用模式】

1. ❌ 总结式叙事（告诉而非展示）
   "经过三天的苦修，他的修为有了很大提升"
   ✅ 用一个具体场景展示提升的效果

2. ❌ 情感宣告（直接说情感而非表现情感）
   "他感到非常愤怒"
   ✅ "他的手指陷进了掌心的肉里，指节发白。"

3. ❌ 列举式描写（一二三四列举）
   AI喜欢列举角色的特点/感受
   ✅ 用叙事自然地展现，一段文字只聚焦一两个特点

4. ❌ 对称式表达（AI偏爱的工整句式）
   "既有XXX的坚定，又有XXX的柔软"
   ✅ 用不对称的、更自然的表达

5. ❌ 万能感叹（空洞的感慨）
   "这就是修仙者的世界吗？" / "果然，强者的世界不同凡响"
   ✅ 用具体的感官细节代替空洞感叹
```

## 五、风格渲染技巧

### 5.1 "五感法"描写

好的描写调动读者的五种感官：

```
视觉：颜色、形状、光影、动态
听觉：声音、寂静、回声、节奏
触觉：温度、质感、痛感、风
嗅觉：气味、空气质感
味觉：口中的味道（紧张时的铁锈味、放松时的茶香）

一个场景至少调动2-3种感官，但不要五种全上。
```

### 5.2 "冰山理论"应用

不要把所有信息都写出来。让读者去猜、去想、去期待：

```
写出来的（冰山水面以上）：
- 角色的行动和对话
- 必要的环境描写
- 关键信息

隐藏的（冰山水面以下）：
- 角色的全部计划（让读者猜）
- 反派的真实目的（让读者好奇）
- 伏笔的含义（让读者恍然大悟）
```

## 六、章节字数控制

```
字数分配参考（3000字章节）：

开场Beat：300-500字（10-15%）
推进Beat×2：1000-1600字（35-55%）
高潮Beat：500-1000字（20-30%）
收尾Beat：300-500字（10-15%）

注意：
- 对话多的章节天然字数偏多，注意控制
- 战斗章的字数容易膨胀，要精简
- 每章控制在2000-4000字之间
- 超过4000字考虑拆成两章
```
