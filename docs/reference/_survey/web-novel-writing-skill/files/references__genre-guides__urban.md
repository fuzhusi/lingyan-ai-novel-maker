# 都市 题材指南

> 都市文扎根于现代生活，却又超越现实，给读者"如果我也能这样"的代入感。本指南帮助你搭建一个既有现实质感又有爽文内核的都市故事。

---

## 一、题材核心特征

### 现代都市背景
- 故事发生在当代或近现代都市
- 读者对场景有真实认知——写错了会被抓包
- 生活细节要真实：交通、饮食、社交、工作场景

### 常见子类型

| 子类型 | 核心设定 | 代表作 |
|--------|----------|--------|
| 都市异能 | 隐藏在现代社会的超自然力量 | 《我有一座恐怖屋》 |
| 兵王回归 | 退伍/退隐强者回归都市 | 《超级兵王》 |
| 神医/鉴宝 | 拥有某种专业领域的绝技 | 《超级医生》 |
| 重生经商 | 带着前世记忆重回过去赚钱 | 《重生之神级学霸》 |
| 赘婿逆袭 | 被看不起的女婿其实身世惊人 | 《神级龙卫》 |
| 都市修仙 | 在现代社会修炼 | 《都市之最强纨绔》 |

### 与玄幻的关键区别
- **背景限制**：现代社会有法律、科技、社会规则的约束
- **力量隐蔽**：异能/修炼通常需要隐藏在普通人面前
- **关系复杂**：职场、家庭、朋友、恋人的社会关系网更复杂
- **爽点来源**：不仅是战斗，更多是身份反差、财富碾压、社会地位逆袭

## 二、经典套路

### 赘婿逆袭
- **开局**：入赘女方家庭，被岳母/大舅子/所有人看不起
- **转机**：神秘身份曝光（豪门少爷/特种兵王/修仙传人）
- **爽点节奏**：小打脸（家庭内部）→ 中打脸（商场/社交场合）→ 大打脸（身份揭露）
- **注意**：不要让女主也看不起主角，那样读者不会喜欢女主

### 兵王回归
- **开局**：退役特种兵/杀手回到普通生活
- **冲突来源**：身边的人被欺负、暗世界的旧敌追来、被迫卷入纷争
- **爽点**：用军事级别的能力碾压都市小混混，反差极大
- **注意**：要给主角回归的理由（保护某人/承诺/厌倦杀戮）

### 神医/鉴宝
- **开局**：获得某种特殊感知能力（透视/神农传承/古玩鉴定术）
- **成长路线**：小诊所→大医院→医学界权威 / 地摊淘宝→拍卖会→国宝鉴定
- **爽点**：专业碾压（打脸那些质疑他的专家），妙手回春（救了别人救不了的人）
- **注意**：专业知识要下功夫研究，写错了会被读者喷

### 重生经商
- **开局**：带着未来10-20年的记忆回到过去
- **金手指**：知道哪些股票会涨、哪些行业会爆发、哪些技术会颠覆世界
- **爽点**：精准预判带来的"先知"感，财富的滚雪球式增长
- **注意**：不能只靠信息差，要有竞争对手和变数

## 三、核心爽点

### 身份揭露
- **铺垫**：所有人都以为主角是废物/穷人/普通人
- **爆发**：通过某个事件，主角的真实身份/能力暴露
- **关键**：旁观者的反应决定了爽度——之前越看不起，现在越震惊
- **频率**：每个圈层揭露一次（家庭→公司→城市→全国）

### 财富碾压
- **场景设计**：对方炫富→主角不动声色→拿出更高级的东西
- **注意**：不能纯靠砸钱解决问题，那样很无聊。财富是工具，不是目的
- **高级写法**：财富带来的不是物质享受，而是选择的自由和保护所爱之人的能力

### 能力展示
- **设计**：每次展示的能力层级递进，不要一开始就展示全部
- **场景**：被人质疑→用实力打脸→赢得尊重/恐惧
- **注意**：要有"不能随便使用能力"的限制条件（暴露风险/副作用/规则限制）

### 感情线推进
- **都市文的感情线权重远高于玄幻**
- **推进节奏**：暧昧期→确认关系→经受考验→感情深化
- **注意**：女性角色要有独立人格和自己的事业/目标，不能只是主角的附属品

---

## 四、节奏特点

### 事件驱动结构
都市文不像玄幻有"打怪升级"的固定框架，更依赖一个个事件推动：

```
事件1：职场危机（5-8章）
  → 解决 + 获得资源/关系
事件2：感情误会（3-5章）
  → 解决 + 感情升温
事件3：暗世界威胁（8-12章）
  → 解决 + 实力提升
事件4：家族内斗（10-15章）
  → 解决 + 身份部分揭露
……循环推进
```

### 多线交织
都市文通常有3-4条并行的故事线：
- **主线**：核心冲突/终极目标
- **事业线**：商战/职场发展
- **感情线**：恋爱/家庭关系
- **暗线**：隐藏势力/身世之谜

**技巧**：每章推进1-2条线，不同线之间交替，保持读者的新鲜感。

## 五、世界观设计建议

### 隐藏的超自然世界
- **表面**：普通的现代社会
- **暗面**：修炼者/异能者隐藏在社会各个角落
- **管理机构**：官方或半官方的超自然事务管理组织
- **规则**：不能在普通人面前暴露超自然力量，否则会被处罚
- **优势**：能写战斗和修炼，又有都市文的烟火气

### 纯现实世界
- 没有超自然元素，靠商战、智斗、人脉推动
- **难度更高**：需要真实的商业/政治/社会知识
- **爽点来源**：智商碾压、信息差利用、人脉布局
- **适合**：重生经商类、职场类

## 六、常见坑点

| 坑点 | 表现 | 解决方案 |
|------|------|----------|
| 金手指过强 | 主角没有挑战，全程碾压 | 设置明确的能力限制和强于主角的对手 |
| 后宫失控 | 女性角色越加越多，每个人戏份越来越少 | 控制在3-4个主要女性角色以内 |
| 现实逻辑崩塌 | 主角随意杀人却没有法律后果 | 尊重基本的社会规则，或设定好规避手段 |
| 职场/商战假 | 公司运作完全不符合现实 | 研究基本的商业知识和职场规则 |
| 装逼过度 | 全程打脸没有正常互动 | 安排日常生活和真实的人际关系 |
| 配角降智 | 反派和配角智商集体下线 | 反派要有合理的计谋和行动逻辑 |

## 八、平台策略

### 番茄小说（都市文重地）
- 偏好：快节奏、密集打脸、短章节
- 读者特征：碎片化阅读，1-3章定去留
- 建议：第一章就要有明确的冲突和金手指展示，3章内完成第一次打脸
- 热门标签：赘婿、兵王、神医、重生

### 起点中文网
- 偏好：有深度的世界观和角色塑造
- 读者特征：能接受慢热，但要求逻辑自洽
- 建议：前10章立住世界观和人设，爽点可以稍缓但不能无聊
- 热门标签：都市异能、重生经商、系统流

### 七猫小说
- 偏好：与番茄类似，但更偏向中老年读者
- 读者特征：喜欢传统价值观、家庭/家族题材
- 建议：主角形象正面，家庭关系是重要元素

> 💡 **核心建议**：都市文的本质是"在现实中创造超现实的可能"。读者在熟悉的都市环境中，体验主角超越常人的精彩人生。关键在于：现实的底色越真实，超现实的部分就越让人心动。
