# 节奏分析维度

> 网文节奏是留住读者的命脉。本文档提供多维度的节奏分析框架和评分标准。

---

## 一、爽点密度检查

### 定义
- **小爽点**：打脸、获得宝物、小胜利、暧昧互动、悬念揭晓等
- **大爽点**：境界突破、越级大战胜利、身份揭露、关键复仇、告白/确认关系等
- **超级爽点**：改变格局的事件——称霸一方、大仇得报、终极对决等

### 密度标准

| 爽点级别 | 推荐频率 | 过疏信号 | 过密信号 |
|----------|----------|----------|----------|
| 小爽点 | 每1-2章至少1个 | 连续3章无爽点 | 每段都在爽（审美疲劳） |
| 大爽点 | 每10-15章1个 | 超过20章无大爽点 | 每5章一个大爽点（贬值） |
| 超级爽点 | 每卷1-2个 | 一卷结束无高潮 | 一卷超过3个（失去分量） |

### 评分标准
- ⭐⭐⭐⭐⭐ 完美：爽点分布均匀，大小交替，节奏感强
- ⭐⭐⭐⭐ 良好：基本达标，偶有间隔过长
- ⭐⭐⭐ 及格：爽点存在但分布不均
- ⭐⭐ 不足：大段剧情缺乏爽感
- ⭐ 严重不足：读者可能弃书

## 二、3:1 节奏比例验证

### 原则
每3段紧张/激烈的内容之后，安排1段舒缓/日常/温馨内容，形成"紧-紧-紧-缓"的呼吸节奏。

### 紧张内容类型
- 战斗/对抗场景
- 紧迫的任务/逃亡
- 激烈的冲突/争论
- 高悬念的剧情推进

### 舒缓内容类型
- 日常互动/搞笑段子
- 角色情感交流
- 修炼/成长描写（非突破）
- 世界观展示/旅途风景
- 收获/整理战利品

### 检查方法
逐章标记"紧"或"缓"，连续超过5章"紧"→ 读者可能疲惫；连续超过3章"缓"→ 读者可能无聊。

### 评分标准
- ⭐⭐⭐⭐⭐ 完美：严格遵循3:1比例，紧缓转换自然
- ⭐⭐⭐⭐ 良好：大致符合比例，偶有偏差但不影响体验
- ⭐⭐⭐ 及格：有意识控制但执行不稳定
- ⭐⭐ 不足：连续大段同节奏，缺乏变化
- ⭐ 严重不足：全程一个节奏，无呼吸感

## 三、情绪曲线分析

### 每章情绪值标注
为每章打一个情绪分（-5 到 +5）：
- +5：极度兴奋/感动（大高潮、极致爽点）
- +3：愉悦/紧张（小胜利、有趣情节）
- +1：轻松/平和（日常、铺垫）
- 0：平淡（纯过渡）
- -1：轻度压抑（小挫折、误会）
- -3：沉重/焦虑（重大危机、角色受伤）
- -5：极度悲伤/绝望（角色死亡、重大失败）

### 健康曲线特征
```
情绪值
  +5 |          *              *
  +3 |    *   *   *      *  *   *
  +1 |  *  * *     *   *  *       *
   0 | *              *
  -1 |              *
  -3 |           *
  -5 |
     +---章节---→
```
关键特征：
- 整体趋势向上（爽文）或波动中推进（虐文）
- 每次低谷后都有更高的峰值
- 避免长期在0线附近徘徊（无聊）
- 避免持续-3以下超过5章（读者受不了）

### 评分标准
- ⭐⭐⭐⭐⭐ 情绪波动丰富，高低交替，总体积极向上
- ⭐⭐⭐ 有波动但幅度不够或过于平缓
- ⭐ 情绪线平坦如水，缺乏起伏

## 四、信息密度检查

### 每章信息类型占比

| 信息类型 | 推荐占比 | 说明 |
|----------|----------|------|
| 剧情推进 | 40-50% | 核心事件发展 |
| 人物互动/对话 | 20-30% | 展现角色性格和关系 |
| 战斗/冲突描写 | 10-25% | 视场景而定 |
| 世界观/设定说明 | 5-15% | 穿插在剧情中，忌大段独白 |
| 心理描写 | 5-10% | 适度揭示角色内心 |
| 环境描写 | 3-8% | 烘托氛围，不宜过长 |

### 常见问题
- **信息过载**：一章塞入3个以上新设定 → 读者记不住
- **信息饥渴**：连续多章不推进主线 → 读者不满
- **设定倾泻**：整段解释世界观，像教科书 → 直接劝退
- **对话空转**：大段对话不推动剧情也不展现人物 → 纯水字数

### 评分标准
- ⭐⭐⭐⭐⭐ 信息分布均衡，设定融入剧情，无冗余
- ⭐⭐⭐ 部分章节信息过密或过疏
- ⭐ 严重失衡，大段灌设定或长期不推进

## 五、章节长度一致性

### 标准
- 推荐单章字数：2000-3000字（平台标准章）
- 波动范围：±20%以内为正常
- 连续3章以上字数差异超过50%→ 节奏混乱

### 检查
统计近10章字数，计算均值和标准差。标准差/均值 > 0.3 则需要调整。

## 六、钩子有效性评估

### 章末钩子类型

| 钩子类型 | 示例 | 效力 |
|----------|------|------|
| 悬念型 | "门后传来一声惨叫——" | ⭐⭐⭐⭐⭐ |
| 转折型 | "他以为一切结束了，直到看见那张脸。" | ⭐⭐⭐⭐⭐ |
| 预告型 | "三天后，就是宗门大比。" | ⭐⭐⭐ |
| 期待型 | "他盘膝而坐，准备突破。" | ⭐⭐⭐⭐ |
| 情感型 | "她转身走了，没有回头。" | ⭐⭐⭐⭐ |
| 无钩子 | "他回到房间，沉沉睡去。" | ⭐ （禁止！）|

### 检查标准
- 每章结尾必须有明确钩子
- 钩子类型不宜连续重复3次以上
- 钩子承诺必须在后续章节兑现

## 七、水字数检测

### 常见水字数模式
- **重复描写**：同一件事用不同措辞说了两三遍
- **无效心理**：大段"他想了又想，犹豫了又犹豫"
- **凑字战斗**：对招拆招写了几百字，对剧情无影响
- **路人反应**：大量围观群众的惊叹、议论（偶尔可以，不宜每次）
- **回顾总结**：角色回顾前情，重复已知信息

### 检测规则
- 删除某段后，剧情/人物/氛围是否有损失？
- 若无损失→该段为水字数，应删除或重写
- 允许水分率 ≤ 10%，超过则需精简

### 评分标准
- ⭐⭐⭐⭐⭐ 每段都有存在的价值，零冗余
- ⭐⭐⭐ 有少量可删段落但不影响体验
- ⭐ 大量注水，严重拖沓
