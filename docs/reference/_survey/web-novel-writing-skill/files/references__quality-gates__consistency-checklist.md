# 一致性检查清单

> 每章完成后必须执行的一致性校验流程，防止设定崩塌和逻辑矛盾。

---

## 一、设定一致性

### 力量体系规则
- [ ] 本章出现的战斗/修炼是否符合已建立的力量体系？
- [ ] 境界压制关系是否一致？（如：金丹期能否挡住元婴期一击？）
- [ ] 技能/法术的使用条件和代价是否与前文一致？
- [ ] 是否出现了未在体系中定义的新能力？若有，是否做了合理解释？

**违规示例**：前文设定"炼气期无法御剑飞行"，本章主角炼气九层却突然御剑赶路。

### 地理空间准确性
- [ ] 地点之间的距离和方位是否与世界地图一致？
- [ ] 出发地→目的地的旅途时间是否合理？
- [ ] 场景内部布局是否前后一致？（如：酒楼是二层还是三层？）
- [ ] 地名拼写是否统一？（如：不要一会儿"青云山"一会儿"青云峰"指同一地点）

**违规示例**：第20章说"从东城到西城需要半天"，第45章角色"片刻间便穿过全城"。

### 势力与阵营逻辑
- [ ] 各势力的立场是否与之前一致？
- [ ] 势力之间的同盟/敌对关系是否有变化？变化是否有剧情铺垫？
- [ ] 势力内部的等级制度是否统一执行？

---

## 二、时间一致性

### 事件时间线
- [ ] 本章事件发生的时间点是否明确？
- [ ] 是否与前后章节的时间线连贯？
- [ ] 同时发生的多线剧情，时间是否对齐？
- [ ] 季节/天气描写是否与时间线吻合？

**检查方法**：维护一条主时间线表格，每章标注"第X天/第X月"。

### 旅途时间
- [ ] 角色从A到B花费的时间是否与设定距离匹配？
- [ ] 交通方式是否影响了旅途时间？（步行 vs 御剑 vs 传送阵）
- [ ] 角色在旅途中是否有足够的休息和补给描写？

### 年龄推进
- [ ] 主要角色的年龄是否随时间正确增长？
- [ ] 闪回/回忆中的年龄描述是否与时间线一致？
- [ ] 角色外貌是否与年龄匹配？（修仙类：境界延寿规则是否一致？）

**违规示例**：主角16岁入门，经历了"三年苦修"后，下一章说他"年仅十八"。

---

## 三、物品一致性

### 库存追踪
- [ ] 角色获得的物品是否记录在案？
- [ ] 使用/消耗的物品是否从库存中扣除？
- [ ] 丢失/赠送的物品是否标记？
- [ ] 角色是否使用了不在库存中的物品？

**追踪模板**：

| 物品名 | 获得章节 | 使用/消耗章节 | 当前状态 | 备注 |
|---------|----------|---------------|----------|------|
| 破天剑 | 第12章   | —             | 持有中   | 主武器 |
| 回春丹×3 | 第18章 | 第22章用1枚   | 剩余2枚  | 疗伤用 |
| 储物戒 | 第8章    | —             | 佩戴中   | 空间10立方 |

### 装备状态
- [ ] 武器/装备是否在战斗中受损？受损后是否修复？
- [ ] 消耗品（丹药、符箓等）数量是否持续递减？
- [ ] 角色换装后，是否还穿着旧装备？

**违规示例**：储物戒在第30章被抢走，第35章角色却"从储物戒中取出丹药"。

---

## 四、称呼一致性

### 人物称谓
- [ ] 角色之间的称呼是否固定？（师兄/师弟、少主/属下）
- [ ] 关系变化后称呼是否合理改变？（陌生人→朋友→兄弟）
- [ ] 同一角色在不同场合的称呼是否有区分？（正式场合/私下）
- [ ] 配角提到主角时用的名字/称号是否一致？

**称呼关系表模板**：

| 说话者 | 称呼对象 | 称呼方式 | 场合 | 变化节点 |
|--------|----------|----------|------|----------|
| 主角   | 师父     | 师父/老头子 | 正式/私下 | — |
| 女主   | 主角     | 你/臭小子→名字→夫君 | — | 第50章确认关系 |

---

## 五、外貌一致性

### 体貌特征
- [ ] 角色的身高、体型描写是否前后统一？
- [ ] 发色、瞳色等显著特征是否一致？
- [ ] 疤痕、胎记等标志性特征是否持续存在？
- [ ] 着装描写是否与场合/时间匹配？

**角色外貌档案**（每个重要角色应记录）：
```
姓名：林逸
身高：约一米八
体型：清瘦但结实
发色：黑色，常束高马尾
瞳色：深褐色（突破后偶尔泛金光）
特征：左颊一道淡疤（第5章受伤所致）
常穿：青灰色长袍，腰悬破天剑
```

**违规示例**：第10章写女主"一头乌黑长发"，第60章写"她金色的长发在风中飞舞"。

---

## 六、能力一致性

### 技能使用检查
- [ ] 角色使用的技能是否已学会/领悟？
- [ ] 技能威力是否与角色当前境界匹配？
- [ ] 是否突然展现出未曾修炼的能力？
- [ ] 先前受伤/封印导致的能力限制是否仍在生效？

### 能力上限检查
- [ ] 角色是否超出了当前境界的能力上限？
- [ ] "以弱胜强"的幅度是否在合理范围内？（通常不超过两个小境界）
- [ ] 角色是否遗忘了已有的强力技能？（遇到困境时却不用）

**违规示例**：主角在第40章学会火系功法，但第38章就已经在使用火焰攻击了。

---

## 执行流程

### 每章校验
1. 完成章节初稿
2. 对照本清单逐项检查
3. 查阅人物档案库确认一致性
4. 查阅时间线表确认时间一致
5. 查阅物品追踪表确认库存正确
6. 标记可疑点并修正

### 每卷校验（每30-50章）
1. 回顾全卷主要事件时间线
2. 盘点所有角色当前状态
3. 检查力量体系是否有偷偷膨胀
4. 确认所有伏笔的状态

> ⚠️ **AI特别注意**：每次生成新章节前，必须先读取人物档案和世界设定文件，不要凭"记忆"写作——AI没有真正的记忆，只有文档中的记录才是可靠的。
