# Phase 8: 质量审查 & 一致性校验

> **阶段编号**: Phase 8 / 10
> **执行角色**: 🔍 质检审稿员
> **触发条件**: Phase 7 完成，正文已生成
> **阶段目标**: 对生成的正文进行全方位质量审查，确保设定一致性和文本质量
> **输出产物**: `reviews/chapter-XXX-review.md` 审查报告 + 修改指令

---

## 一、阶段概述

质量审查是反幻觉系统的最后一道防线。AI在生成正文时，不可避免地会出现各种一致性问题和质量缺陷。本阶段通过 **八维评分系统** 进行全方位扫描，发现问题并触发修改。

**核心原则**：宁可多花时间审查，也不要放过一个设定BUG。读者是最好的"找茬者"——如果你不先找到问题，读者会找到并扣分。

**角色转换提醒**：质检审稿员必须以"挑刺者"心态工作，而非"创作者"心态。审查时要假设"这篇文章一定有问题"。

### 2.2 各维度详细评分标准

#### 🔴 维度一：设定一致性（权重×2）

```
检查项：
□ 力量体系是否符合rules.md？
  - 角色使用的能力是否在其境界范围内？
  - 战斗结果是否符合境界差距规则？
  - 有没有"凭空冒出"的能力？

□ 世界规则是否被遵守？
  - 地理距离和旅行时间是否合理？
  - 经济系统（货币/资源）是否一致？
  - 社会规则（修仙界的等级制度等）是否正确？

□ 物品/功法是否前后一致？
  - 之前提到的物品属性是否变了？
  - 功法效果是否和设定一致？

评分标准：
100分：完全一致，零错误
90分：有极微小的模糊处，不影响阅读
80分：有1处需要修正的不一致
<80分：有多处不一致——🔴 必须修改
```

#### 🔴 维度二：人物一致性（权重×2）

```
检查项：
□ 角色行为是否符合五维人格DNA？
  - 理智型角色是否做了冲动的事（无铺垫）？
  - 独立型角色是否突然变得依赖他人？

□ 角色说话是否符合设定的说话风格？
  - 语气词、句式长度、用词习惯
  - 口头禅是否正确使用（不过度也不遗漏）

□ 行为红线是否被触犯？
  - 角色做了角色卡中标记"绝不会做"的事？

□ 角色的知识边界是否正确？
  - 角色说出了他此时不可能知道的信息？

评分标准：
100分：所有角色完全在人设内
90分：有轻微的风格偏差
80分：有1处明显的角色失真
<80分：有角色严重OOC——🔴 必须修改
```

#### 🟠 维度三：时间线逻辑

```
检查项：
□ 章节内的时间流逝是否合理？
□ 与上一章的时间衔接是否正确？
□ 白天/夜晚/季节是否连贯？
□ 角色受伤后的恢复时间是否合理？
□ 同一时间段内，其他角色的行为是否自洽？

评分标准：
100分：时间线完全自洽
90分：时间感略模糊但不矛盾
85分：有1处时间跳跃缺乏说明
<85分：有明显的时间线矛盾——🟠 需要修改
```

#### 🟠 维度四：伏笔连贯性

```
检查项：
□ 计划在本章回收的伏笔是否正确回收？
□ 新埋的伏笔是否自然（不突兀）？
□ 是否意外提前揭露了不该揭露的信息？
□ 与伏笔管理表是否同步？
□ 之前提到过的线索在本章是否被遗忘？

评分标准：
100分：伏笔处理完美
90分：伏笔处理得当，可微调
85分：有1处伏笔被遗漏或处理不当
<85分：有伏笔被矛盾性处理——🟠 需要修改
```

#### 🟡 维度五：节奏与爽点

```
检查项：
□ 本章的节奏是否符合细纲设计？（⚡紧/🔥推/🌊缓）
□ 爽点是否在预定位置出现？
□ 爽点的冲击力是否足够？
□ 紧张→缓冲的过渡是否自然？
□ 是否有"注水"感（无意义的段落）？

评分标准：
100分：节奏完美，爽点到位
90分：节奏整体良好
80分：有部分拖沓或爽点力度不够
75分：节奏有明显问题——🟡 建议修改
<75分：严重拖沓或爽点缺失——需要修改
```

#### 🟡 维度六：文笔质量

```
检查项：
□ 是否存在Phase 7禁用词汇列表中的词？
□ 是否存在禁用句式结构？
□ 是否存在禁用叙事模式（告诉而非展示）？
□ 对话是否自然、有区分度？
□ 描写是否有功能性（非纯堆砌）？
□ 句式是否有变化（长短交替）？
□ 是否有"AI味"？（整体感受）

评分标准：
100分：文笔流畅自然，毫无AI感
90分：整体良好，个别句子可优化
80分：有少量AI痕迹
75分：AI痕迹明显——🟡 建议修改
<75分：大段AI式表达——需要大幅修改
```

#### 🟢 维度七：信息密度

```
检查项：
□ 本章是否推进了至少一个剧情点？
□ 是否有冗余信息（读者已知的信息重复说明）？
□ 新信息的引入是否自然？
□ 信息量是否适中（不过载也不太少）？

评分标准：
100分：信息密度完美
85分：略有冗余或稍显密集
65分：明显注水或信息过载——🟢 可选修改
```

#### 🟢 维度八：钩子有效性

```
检查项：
□ 章末是否有明确的钩子？
□ 钩子是否有足够的吸引力？
□ 钩子是否与后续章节的内容匹配？
□ 钩子类型是否有变化（不总是同一种）？

评分标准：
100分：钩子精彩，读者一定会翻下一章
85分：有钩子但力度一般
65分：钩子无力或缺失——🟢 可选修改
```

### 补充审查：灌水检测

除了上述 8 维度外，质检员还需要进行字数效率审查：

- **纯环境描写占比**：是否超过全章 15%？（超过则可能灌水）
- **无效对话检测**：是否有角色说了 3 句以上不推进剧情的废话？
- **重复信息检测**：是否在本章中重复了前几章已经交代过的信息？
- **回忆/闪回滥用**：本章是否有超过 500 字的回忆段落？（除非剧情需要）

灌水严重（占全章 30% 以上无效内容）= 🟡重要 级别问题，需在 Phase 10 中削减。

## 三、综合评分计算

```
综合评分公式：

总分 = (设定一致性×2 + 人物一致性×2 + 时间线逻辑 + 伏笔连贯性
       + 节奏与爽点 + 文笔质量 + 信息密度 + 钩子有效性) / 10

评级标准：
95-100分：⭐⭐⭐⭐⭐ 优秀 — 可直接发布
85-94分：⭐⭐⭐⭐ 良好 — 微调后发布
75-84分：⭐⭐⭐ 合格 — 需要修改
65-74分：⭐⭐ 不合格 — 需要大幅修改
<65分：⭐ 严重不合格 — 考虑重写
```

## 五、自动触发规则

```
审查结果 → 自动流转规则：

1. 如果存在任何 🔴 致命问题
   → 强制进入 Phase 10 修改，不询问用户
   → 修改完成后重新进入 Phase 8 审查

2. 如果 🟠 严重问题 ≥ 2个
   → 强制进入 Phase 10 修改

3. 如果综合评分 < 75 分
   → 建议重写（Phase 7），由用户决定

4. 如果综合评分 ≥ 85 分且无 🔴🟠 问题
   → 直接进入 Phase 9（状态同步）

5. 其他情况
   → 由用户决定是否修改
```

## 六、审查技巧

### 6.1 常见AI幻觉模式（重点检查）

```
高频幻觉类型：

1. 能力幻觉：角色使用了当前境界不具备的能力
2. 知识幻觉：角色说出了他不可能知道的事情
3. 位置幻觉：角色突然出现在不合理的位置
4. 物品幻觉：之前已经丢失/使用的物品又出现了
5. 关系幻觉：角色称呼/态度与设定不一致
6. 时间幻觉：时间流逝与事件不匹配
```

### 6.2 交叉验证方法

```
对每个可疑点，进行三源交叉验证：

1. 查 rules.md — 是否违反硬规则？
2. 查 角色卡 — 是否符合角色设定？
3. 查 前文 — 与之前的章节是否矛盾？

三源都通过 → 标记为安全
任一源不通过 → 标记为问题
```
