# Phase 7a: 黄金三章特化生成

网络小说的生死存亡，往往取决于前三章（约 6000-8000 字）。普通的写作指令（Phase 7）节奏过平，大模型容易写出大段的背景设定。因此，当系统检测到用户要求写第 1、2、3 章时，**必须强制调用本特化指令**。

## ❌ 绝对禁止的开篇模式（大模型通病）
- 第一段开始长篇大论介绍世界观（“在苍茫的九州大地上，有三大宗门…”）
- 花费 1000 字描写主角的身世、长相、和周围配角无意义的寒暄。
- 在前三章让主角平平淡淡地修炼、种田（除非是极其偏门的种田文）。

## 📝 各章硬性写作要求

### 📖 第一章：强矛盾切入与金手指觉醒
**核心任务：拉住读者的眼球，抛出核心痛点。**
- **字数分配**：
  - `0 - 500字`：**矛盾直入**。开篇就是危机或极具冲突的场景（被退婚、被审判、被追杀、被开除）。
  - `500 - 1500字`：**侧面展现世界观**。不要大段说明，通过他人的嘲讽、周围的建筑、使用的武器，让读者猜出这是一个什么世界。
  - `1500 - 2500字`：**金手指初现**。在主角最绝望或最关键的时刻，金手指系统（或老爷爷/异能）以极具仪式感的方式觉醒。
- **章尾钩子（Hook）**：主角获得金手指，但面临一个即将到来的直接威胁，悬念拉满。

### 📖 第二章：小试牛刀与信息补全
**核心任务：展示外挂的威力，让读者对未来产生期待。**
- **字数分配**：
  - `0 - 800字`：**化解眼前的危机**。利用刚刚觉醒的金手指，化解上一章结尾的直接威胁（可以不杀敌，但要展现出神奇的效果）。
  - `800 - 1800字`：**研究外挂与痛点梳理**。主角在安全环境下研究金手指的作用，同时回忆或理清自己真正的死敌/目标是谁。
  - `1800 - 2500字`：**确立短期目标**。为了应对马上要到来的更大危机（如三日后的外门大比），主角决定利用金手指去做某事。
- **章尾钩子（Hook）**：主角发现了金手指的一个惊人隐藏用法，或者危机提前降临。

### 📖 第三章：初步打脸与拉开帷幕
**核心任务：完成第一个小爽点，并引出更长远的主线。**
- **内容要求**：
  - **完成第一次压制**：让之前瞧不起主角的人大跌眼镜（打脸）。这里的打脸不需要太大，但要精准、爽快。
  - **引出大背景**：在这个小事件解决后，偶然带出一个更大的世界背景线索（比如打败了恶霸，发现他身上有某个神秘组织的信物）。
  - **留白与期待**：主角踏上真正的旅途，读者已经清楚他最大的底牌（金手指）和他最终的敌人。
- **章尾钩子（Hook）**：引出一个巨大的悬念，或者一个高位格的新角色登场。

## 🛠️ 执行规范
当你执行本指令时，你必须：
1. 调出《角色卡》和《金手指设定模板》。
2. 严格控制世界观说明的字数（**设定抛出率 < 10%**）。
3. 确保你的句子短促、有力。减少无意义的对话。
