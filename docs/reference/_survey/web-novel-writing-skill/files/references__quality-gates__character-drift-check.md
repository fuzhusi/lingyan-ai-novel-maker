# 人物漂移检测

> AI写作中最常见的问题之一是角色"失忆"——前后判若两人。本文档提供系统化的人物一致性检测方法。

---

## 一、性格DNA偏移检测

### 五维性格模型
每个角色在创建时应定义五个核心维度的评分（1-10）：

| 维度 | 说明 | 低分表现 | 高分表现 |
|------|------|----------|----------|
| 理智 ←→ 冲动 | 决策方式 | 冷静分析、三思后行 | 凭直觉行动、容易上头 |
| 温和 ←→ 强硬 | 人际风格 | 退让妥协、以和为贵 | 寸步不让、强势压人 |
| 独立 ←→ 依赖 | 合作方式 | 独来独往、不信任他人 | 重视团队、需要陪伴 |
| 乐观 ←→ 悲观 | 心态底色 | 积极向上、相信未来 | 消极怀疑、预期最坏 |
| 诚实 ←→ 狡诈 | 行事手段 | 坦荡直率、不善伪装 | 善于算计、口蜜腹剑 |

### 偏移检测方法

**步骤一**：记录角色的性格DNA基线
```
角色：林逸
理智 ←→ 冲动：7（偏理智，但对亲近之人会冲动）
温和 ←→ 强硬：4（偏温和，话不多但关键时刻果断出手）
独立 ←→ 依赖：6（善良但不圣母，对敌人不留情）
乐观 ←→ 悲观：5（看情况，平时乐观，涉及底线时悲观）
诚实 ←→ 狡诈：8（极度诚实，源于前世记忆和金手指）
```

**步骤二**：每10章重新评估当前表现，得出"当前值"

**步骤三**：计算偏移量
- 单维度偏移 > 2 → ⚠️ 黄色预警（需要情节解释）
- 单维度偏移 > 3 → 🔴 红色预警（角色已漂移）
- 总偏移量（五维绝对值之和）> 8 → 🔴 角色已面目全非

**步骤四**：判定偏移是否合理
- 有具体事件触发？（亲人死亡导致善良→冷酷 ✅）
- 渐进式变化？（不是一夜之间从极端到另一极端 ✅）
- 有角色自身意识到变化的描写？✅
- 以上都没有？→ 这是漂移，需要修正 ❌

## 二、行为红线违规检测

### "绝不清单"
每个角色应该有一份"绝不会做的事"清单：

```
角色：林逸
绝不清单：
❌ 绝不背叛朋友（底线）
❌ 绝不欺负弱者（价值观）
❌ 绝不跪地求饶（性格）
❌ 绝不放弃修炼（核心驱动力）
❌ 绝不对女主撒谎（感情线设定）
```

```
角色：反派·赵天磊
绝不清单：
❌ 绝不承认自己的错误
❌ 绝不真心帮助他人（除非有利可图）
❌ 绝不违背家族利益
```

### 检测流程
1. 每章完成后，扫描角色的关键行为
2. 与"绝不清单"逐项比对
3. 若触碰红线 → 必须有极其充分的理由和铺垫
4. 无铺垫触碰红线 → 删除或重写该段

### 违规示例
> 林逸一贯果断自信，却在面对一个无名小卒时突然"吓得双腿发抖，跪地求饶"——除非有极特殊原因（如对方拥有某种精神控制能力），否则这就是严重的角色漂移。

## 三、语言风格一致性

### 语言指纹要素

每个角色的对话应有独特的"语言指纹"：

| 要素 | 说明 | 示例 |
|------|------|------|
| 口头禅 | 标志性用语 | "有意思"、"哼，一群蝼蚁" |
| 用词偏好 | 文雅/粗犷/现代 | 书卷气 vs 江湖气 vs 网络用语 |
| 句式习惯 | 长句/短句/反问 | 老者爱用长句，少年爱用短句 |
| 称呼方式 | 对不同人的称呼 | "小子"vs"阁下"vs"哥们" |
| 语气词 | 句末习惯 | "嘛"、"呢"、"罢了" |
| 幽默方式 | 冷幽默/自嘲/毒舌 | 各有风格 |

### 检测方法
1. 遮住角色名，只看对话，能否辨认出是谁在说话？
2. 将同一角色不同章节的对话并排对比，风格是否一致？
3. 配角对话是否千人一面？（AI常见问题：所有角色说话都像"文化人"）

### 违规示例
> 粗犷的将军："此事关乎苍生，吾等应当深思熟虑，万万不可操之过急。"
> → 这不是将军说话的方式，应该是："妈的，打就打！想那么多有屁用！"

## 四、动机一致性

### 动机链检测
每个重要行为应能追溯到角色的核心动机：

```
核心动机（终极目标）
  └─ 阶段动机（当前弧光目标）
      └─ 即时动机（本场景为什么做这件事）
          └─ 具体行为
```

**示例**：
```
核心动机：为灭门之仇复仇
  └─ 阶段动机：提升实力到能挑战仇人的程度
      └─ 即时动机：争夺秘境中的天材地宝
          └─ 行为：与其他弟子争抢灵果
```

### 检测标准
- [ ] 角色的行为是否能向上追溯到核心动机？
- [ ] 若角色做了与动机无关的事，是否有合理解释？
- [ ] 角色是否突然忘记了自己的目标？（如：复仇者突然去参加选美比赛？）
- [ ] 多个动机冲突时，角色的选择是否符合优先级？

### 违规示例
> 角色的核心动机是"拯救被囚禁的母亲"，但主角在得知母亲的线索后，却花了20章去参加一个与主线无关的武术大会，期间完全没有提到母亲——这就是动机遗忘。

## 五、成长合理性

### 成长弧线验证

角色的变化必须经过"事件→冲击→挣扎→领悟→改变"的完整链条：

| 阶段 | 说明 | 缺失后果 |
|------|------|----------|
| 触发事件 | 某件事挑战了角色的认知/能力 | 变化无来由 |
| 内心冲击 | 角色被事件影响，产生动摇 | 变化太突然 |
| 内在挣扎 | 旧认知和新认知的冲突 | 变化太容易 |
| 关键领悟 | 角色想通了某个道理 | 变化无深度 |
| 行为改变 | 角色的行为确实发生了变化 | 只说不做 |

### 检测标准
- [ ] 角色的每一次重大变化，是否都有完整的五阶段链条？
- [ ] 变化的幅度是否与触发事件的分量匹配？（小事不应导致性格巨变）
- [ ] 变化是否渐进的而非突变？（除非是极端事件）
- [ ] 成长后是否偶尔"旧习复发"？（真实的成长不是一步到位的）

### 违规示例
> 主角在第1章是个自私冷漠的人，第2章遇到一个老奶奶摔倒后扶了一下，第3章就变成了一个"心怀天下、悲天悯人"的圣人——成长跳跃过大，缺乏可信度。

## 漂移严重度分级

| 等级 | 描述 | 处理方式 |
|------|------|----------|
| 🟢 微漂 | 语气/用词略有不同 | 编辑阶段修正 |
| 🟡 轻漂 | 行为与性格有轻微矛盾 | 补充心理过渡描写 |
| 🟠 中漂 | 角色做出了意外的决定 | 重写该段或补充铺垫 |
| 🔴 重漂 | 角色判若两人 | 必须重写，可能需修改前后文 |

---

## AI写作专用提醒

> ⚠️ AI最容易发生的角色漂移场景：
> 1. **跨章节写作时忘记角色设定**——解决方案：每次生成前重新读取角色档案
> 2. **把所有角色都写成"善解人意"的好人**——解决方案：每个角色应有缺点和阴暗面
> 3. **反派突然变蠢，只为配合主角胜利**——解决方案：反派的智商应始终在线
> 4. **情感关系跳跃式发展**——解决方案：遵循感情升温曲线，不跳步
