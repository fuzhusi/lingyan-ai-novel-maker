# 江南感写作 · jiangnan-feeling-writing

> 不是教你写得"像江南",是教你写得让人疼。

青春回望、缺口里的人、远处的温暖、迟来的那一下疼、为一个信念付出的账——这些东西堆不出来。再多的雨、天台、孤独和短句,也只是仿了个壳。

这个 skill 把那种"江南感"拆成可复用的笔法:让物和动作替人物开口,把宏大的题落进一件小物,在段尾留一记回疼,并在每一个选择背后,压上一份现实的代价。它面向**原创写作、改稿、诊断、大纲**四件事,可被多种模型调用——核心协议与平台无关,各家入口只是换一层壳。

版本:**v1.1.1**

## 先说清楚:它不是"江南附身"

装上它,**不会让你一动笔就自动出江南感**。它不是后台滤镜,是一套**需要主动调用的写作协议**——更像一个懂江南笔法的写作教练加一张检查表,它做不到完全代笔。

用它的时候,模型不会直接吐漂亮句子,而是先被这套协议逼着做几件事:定题材与阶段(10 个 preset 选一个)→ 立人物缺口 → 给选择压上现实代价 → 挂四个笔法指纹 → 写完用 24 分评分门自检。

所以请有这样的预期:

- **要主动调用**。你如果不喊它,模型还是平时的写法;它管的是单次写/改/诊断/大纲任务,不是常驻状态。
- **效果跟着你的输入走**。题目、人物、设定给得越具体,出来越准;只说"写个江南感的故事"会很空。
- **它是辅助,不是出版保证**。内部测试能稳定到 22–24/24,但那证明的是"协议可供调用、风格边界稳定",不等于直接出版级文学。**最后保留什么、删什么、改成什么,仍然需要你来划定**。

一句话:你出题、它按章法落笔、再自检一遍。它负责把江南的笔法拆开摆到你面前,**让文字仍然像人写的,是你要做的事**。

## 快速开始

按你的平台读对应入口:

- **Codex**:从 [`SKILL.md`](SKILL.md) 开始,按其调用流程读 `core/`。
- **Claude**:见 [`adapters/claude/CLAUDE.md`](adapters/claude/CLAUDE.md)。
- **DeepSeek**:把 [`adapters/deepseek/写作模式投喂提示.md`](adapters/deepseek/写作模式投喂提示.md) 复制进对话。
- **通用 LLM**:见 [`adapters/generic/system_prompt.md`](adapters/generic/system_prompt.md)。

核心调用顺序见 [`core/protocol.md`](core/protocol.md);交稿/测试前用 [`core/evaluation.md`](core/evaluation.md) 的 24 分评分门自检。

## v1.1.1 关键点

写作前必须确认**"现实成本 / 为什么他会选择"**:人物不只是被物件触动,还要在钱、身份、关系、工作、名誉、身体、机会或阵营上付出代价。成本必须通过物、动作、对话或制度细节露出来,**不用议论文解释**。
