## 一、样稿摘录与病灶标注

### 样稿 A：《玄学佬你怎么就那么胆小呢》试写章（流水线产，人味分 87–100）

系统日志（`lingyi_setup/review/4_试写/_生成日志.md`）显示大量「人味分 92–100 / ok」落库；
同书盲审沉淀（`writing_directives.md` 开篇）却写明：即便第 1 章双盲审 2/2 追读，
**共性问题仍多到必须写成放量前硬纪律**——「否则每章重犯」。

#### 开头 300 字：能抓住人，但靠的是「好对话」不是「戏剧压力」

第1章开场（`4_试写/第1章.md:3-13`）：

> “算命嘞！正宗周易，一杯奶茶钱，不准不要钱！”
> 陈屿从折叠凳上起来，一把摁住马千军的后领……
> 网吧会员里还剩两块三。新赛季今晚更新……摆一晚上，四卦回本，这账算得他自己都有点臊。

**优点**：人声开场、数字具体（8.8 / 两块三 / 四卦回本）、人物关系立刻可感。
**缺口**：欲望是「回本 / 别被保安赶」，**不是本章核心冲突**（身份暴露 / 被懂行的人识破）。
读者得到的是轻喜剧日常成立，不是「必须翻下一页」的压力。

第3章开场（`第3章.md:3-31`）更好：满爹认出爷爷、三刀印纸、明早八点收走——
**有物、有期限、有不可逆损失**。这恰是全书最「抓得住」的段落，反证默认管线并不稳定产出这种开头。

#### 冲突 / 欲望 / 阻碍：有场面，常缺「本章目标」

- 第2章有清晰对赌（空调房 + 七人 vs 十九人 + 录音）——**戏剧结构完整**，结尾也有外部事件钩。
- 第3章中段食堂场景（`第3章.md:53-117`）情感密度高（覃师傅的桃木锁、「她走得早，管不到我咯」），
  但主角当章主动目标模糊：**摆摊→被拉去摇卦→说了三个字→收钱**。
  盲审沉淀原话：**「本章主角主动目标为零」**（`writing_directives.md:70`）。
- 第4章库房整理（`第4章.md:59-73`）大量登记流水：

> “念。”“蒲团六个，霉边。”“写：蒲团六，霉。”

材质感真实，但**章中脊梁偏弱**——事件（红布包禁开、七捆经书周五认）出现偏晚，
前半是事务流。盲审原话：**「像通知」「正常使用的事情过多」**（`writing_directives.md:69,79`）。

#### 对白质量：市井味是亮点，但「互相通报 / 试探空转」仍高频

好句（有信息差与人物）：

> “你这三枚铜钱，摆了一晚上，没翻过面。”……“网上可教不出你这个。”（第1章）
> “我们十九。”……“你昨天那个七，自家一点没用上，一个不差，全给隔壁了。”（第2章结尾）

坏模式（盲审点名）：

- 试探—嘴硬来回超过两轮不推进：**「一个试探一个嘴硬，两轮没推进」**（`writing_directives.md:49`）
- 同一件事悬念口径不统一：一会儿「门儿清」一会儿「自己也没底」（`:26`）
- 主角用解释把悬念自毁：把「准」拆成话术/巧合，等于替读者把谜底念完（`:95-98`）

#### 场景是否「拍得出来」

**拍得出的**：操场折叠桌与塑料龟壳；满爹库房樟脑味与三刀旧印纸；覃师傅案板上六枚铜钱；
库房登记与三尘「放下」红布包。这些段落镜头感强。

**拍不出 / 梗概化的**：

- 第2章中段「四点到五点人流上来」后的招新问答，密度够但**更像小品串烧**，
  推进主要靠台词接梗，场面结果变化有限。
- 盲审沉淀反复出现「段末贴标签」：动作做完再补「这叫截流」「是递台阶」式意义总结
  （`writing_directives.md:14`）——叙述层替读者「翻译」场面，镜头感被破坏。
- 「慢半拍」「静了一拍」「脑子白了一秒」式量化反应（`:15`）是**舞台指示模板**，
  不是可拍摄的身体动作。

#### 章尾钩子

- 第1章尾：排班表「还是全天」——情绪留白，**不是事件钩**。
  盲审明确反对：**「章末钩不许落在主角犹豫上」**，钩子必须是已发生的事/倒计时/他人既成事实（`:63`）。
- 第2章尾：坐堂 + 录音删不删看明天表现——**有效外部事件钩**。
- 第3章尾：七点山门口 vs 八点收纸车——**双期限冲突**，是全书最强章尾设计之一；
  但同章沉淀又批评「两路时间不冲突等于没有取舍」（`:73`），说明**该结构是后天用特别指示拧出来的，不是默认产出**。
- 第4章尾：“走，带你看看真东西。”——标准邀约钩；盲审要求邀约必须附**不去会失去什么**（`:105`）。

#### 材料密度

非常高，甚至**过密**。用户实测反馈已写进词库 front matter
（`app/services/constraint_bank/L1_writer_anti_ai_taste.md:9`）：

> 2026-09 卷一初稿四宗罪：**细节过密 / 金句密集 / 克制留白套路 / 结构雷同**

样稿A同时具备：
- 具体物价（8.8、三十七块五、护膝七十六、三十块老版门神）
- 身体与器物细节（拇指捋木珠、铜钱磨圆、围裙浆糊渍）
- 以及装饰性细节堆叠风险（正向词库又要求「每场景至少 2 个可核实具体物」）

**病灶不是「缺材料」，是材料未稳定服务于「本章他要什么 + 谁拦他」。**

### 样稿 B：《龙族：同级生》第01章 V1（强指示监督下）

`longzu_setup/review/第01章_退休失败_V1.md` 开头：

> 先醒的是鼻子。
> 铁锈味，冲得发甜……
> 他手里扣着半截砖头。……可惜手在抖。
> 他死过很多次，从没死得这么慢。

**对比默认样稿A**：
- 冷开场有效：感官 + 反常 + 即时身体危机。
- 冲突明确：杀局进行中，身体与意识不匹配（「眼睛和脑子是满的，手脚欠费停机」）。
- 材料与动作绑定：作战靴、烫毛机、挂肉钩、虎口茧、门洞一米二、三步杀局。
- 章尾钩：**「那东西比他快了0.3秒。」**——外部事件 + 不可逆失败。

**仍在的「好看度」问题**（即便这份明显更强）：
- 系统 UI 行（【教程：存活】【失败：死亡】【重试：无】）承担悬念，**戏剧本身略被机制接管**。
- 中段插叙身世（孤儿院/院长/蓝星）仍偏「按需交代」，靠「念头断在这儿」打断——
  与盲审「严禁成段身世 info dump」同题。
- 肉体代价写得细，但**读者对「这具身体是谁、为何在这」的当章欲望**仍主要靠后段记忆翻出。
- 大纲层（`第一卷大纲定稿v3.md`）钩子表、爽点间隔、金句落点非常完整——
  **质量提升首先来自人写的大纲与特别指示，不是默认 prompt 自动达到该水平。**

## 二、盲审意见归纳：阎浮 / 白骨各在杀什么

人格定义（`app/services/blind_review.py:54-86`）：

| 编辑 | 只关心 | 专杀 |
|------|--------|------|
| **尖酸嘴·阎浮** | 读者会不会往下翻 | 开头三行摁不住人、灌水、软钩子、跳段、AI 痕迹（甚至直接绑朱雀检测） |
| **白骨·文学审稿** | 文字是不是「真的」 | 假情绪、假细节（万金油描写）、套话腔、AI 腔（匀速叙述/总结升华/对话念台词） |

### 与样稿对得上的「杀点」（来自 `writing_directives.md` 多轮盲审沉淀）

**阎浮侧（市场/追读）**
1. **开场静物 / 通知式开场**：先写几点在哪谁发围裙——读者「像通知」「舍不得先上肉」。
2. **中段空转**：连续试探问答、推拉戏两轮无推进；手机前 3000 字必须有事发生。
3. **金手指不点亮 / 爽点自毁**：算准了没有第三方验证；主角不停解释「蒙的」泄掉爽感。
4. **章末软钩**：犹豫、没发出去的消息、邀约不附代价。
5. **info dump**：「刚被对话带起来就切一大段家世交代，这里想划走」。
6. **AI 痕迹即毙**：人格里明文写过不了朱雀就毙——**判决被检测器绑架，可能掩盖「故事本身好不好看」**。

**白骨侧（文学真实性）**
1. **段末意义标签 / 作者旁白**：替读者总结「这叫××」。
2. **量化翻译情绪**：慢半拍、静了一拍、白了一秒。
3. **通用情绪件**：「他听见自己开口」「心里一沉」塞进任何稿子都成立。
4. **功能化配角与女主**：一个功能反复用；女主只做观察/暧昧/钩子位。
5. **悬念口径打架 / 规矩说明书**：能力边界成段解释；同一件事三种说法。
6. **金句与对仗排比**：可截图台词、先摆两选项再否定的机器句法。

### 盲审闭环的结构性局限

`build_rewrite_messages`（`blind_review.py:151-177`）规定第二稿：
**「保持人物、事件、结局走向不变，不新增设定、不加新情节线」**。

→ 盲审能逼出「删水段、去标签、改钩子」，**不能逼出「本章目标、冲突设计、场景施工」**。
而「不好看」的主因恰恰在后者。**审→改闭环修的是皮肤，不是骨架。**

## 三、根因假设（按「最可能导致整体不好看」排序）

### 根因 1（最高）：长篇生成粒度是「整章一锅」，大纲节拍在锅里被压成梗概

**证据**
- `writer_chain.py:22-25`：`CHAPTER_WORD_TARGET=2500`，`CHAPTER_WORD_FLOOR=2000`。
- `chapter_runner.py:114` / `routes/generate.py`：一次 `collect_full_text(messages, cfg, word_target)` 写完全章。
- 续写轮 `writer_chain.py:350-358` 的 system 仅：「直接接续前文写下去，不要重复……」——
  **不带约束词库、不带节拍、不带事件清单**；不足 2000 字时用弱指令补血，易灌水。
- 大纲侧已有「【场景节拍】3-5 条…是施工顺序」（`prompt_builder/writer.py:188-194,233-236`），
  但仍是**同一 prompt 里一次铺完 3–5 拍 + 对话 + 心理 + 钩子**。
- 对比：短篇链路有逐节点生成与断点续跑；长篇正文没有同等场景级生成器。

**机制**：2500 字、一次采样、上下文里塞满一致性红线与设定 → 模型最优策略是
「把节拍串成连贯叙述 + 补足字数」，而不是「每一拍拍成可看的戏」。
`writing_directives` 里「不许把多拍合并为梗概式叙述」正是对这条默认失败模式的事后追认。

---

### 根因 2：prompt 层「禁令密、戏剧指令稀」——好看度没有被一等公民化

**证据（writer 注入结构）**
- System：`constraints`（词库装配）+ `skill_prompt`（多为去AI技法）+ 通用「专业网文作家」
  （`writer.py:22-56`）。
- User 块顺序（`writer.py:58-207`）：书名/类型/简介 → 罗盘 → 偏好/文体备忘 → 世界观 →
  大纲树 → 设定 → 出场硬约束 → 人物档案 → 上章结尾 → 摘要/伏笔/事件清单/读者已知/反射/参考 →
  因果/记忆/边界 → **本章大纲** → 节拍施工指令 → 行文指纹修正 → 特别指示 → 字数。
- **唯一系统级「戏剧施工」指令**：
  1. 大纲格式里的【核心事件】【场景节拍】【结尾钩子】（`writer.py:228-240`）；
  2. `chapter_events.py:15-20,70-78` 的「目标-冲突-微结局」事件清单。
- 约束词库 L0/L1 以**怎么不写坏**为主：`L0_core.md` 结构+构式禁令；
  `L1_writer_positive.md` 有人味加法但偏「材料/潜台词/不完美」；
  `L1_writer_anti_ai_taste.md` 又是四组禁令。
- 技能库 13+：钩子/节奏/展示/对话/伏笔/情感/句式/感官/留白/去模板——
  **大量在管「不像 AI」，少有「本章欲望—阻碍—代价—兑现」的场景配方**。

**机制**：模型注意力被大量「别写 X」占满；正向戏剧要求字数少、位置靠后（事件清单/大纲在 user 中后段），
且无场景级验收。调研文档自己已承认方向问题
（`docs/ai-tone-research.md:148`）：

> 「疑似桶」需要正向人类特征……规则禁令产生不了正向特征——策略从「禁止什么」转向「注入什么」

产品层已部分响应（L1_positive、事件清单、指纹注入），但**离「每场戏有目标/冲突/变化」还差一层生成协议**。

### 根因 3：质量门禁优化的是「人味分 / 禁词命中」，不是「好不好看」

**证据**
- `chapter_runner.py:122-139`：`run_gate` + `analyze_ai_tone`，人味分 <90 触发收敛；
  终稿门禁失败才停。**通过条件 = AI 痕迹少**，与追读无关。
- 生成日志：人味分 92–100 连续 ok；同书盲审仍堆出 30+ 条戏剧病。
- 校准点（`data/calibration/points.jsonl`）：human_score 71 ↔ 朱雀 44%——指标对齐的是检测器。
- `skill_gate.py`：对话修饰语、模板结构、段末升华、直述情绪、标点硬限——全是「像不像 AI」。
- 系统审查（`docs/系统审查报告-2026-09.md:34`）：**「人味分无通过线无行动指引（阈值自己都未校准）」**。

**机制**：流水线把「合规文本」当成「可发布章节」。用户看到 ok + 高分，误以为好看度也过关；
实际好看度（钩子、目标、事件密度、对白信息差）**系统内无分、无门禁、无回写**。

### 根因 4：约束词库内部自相矛盾 + 作者协议叠层 → 风格震荡

**证据**
| 指令源 | 要求 | 冲突点 |
|--------|------|--------|
| `L1_writer_positive.md:18-19` | 每场景 ≥2 个可核实具体物 | 与下条对立 |
| `L1_writer_anti_ai_taste.md:14-16` | 每场景只留 1–2 个推进剧情的细节 | 细节过密 vs 过疏 |
| 江南指纹 `skill_system.py:261` + `jiangnan` 协议 | 遮蔽梯≥3 层，禁直接说情绪 | 与下条对立 |
| `L1_writer_anti_ai_taste.md:23-26` | 允许「他很难过」直写 | 留白禁令 vs 情绪直写 |
| `show_dont_tell` skill constraints | 禁止「他很X」 | 与上条再对立 |
| 系统审计 `system-audit-2026-09-17.md:40` | 技能/红线/tone/boundary 各自豁免预算，**最坏破万字** | 注意力稀释 |

`writing_directives` 同时记录两种失败：细节/金句过密 **与** 克制留白套路、
「正常事情过多」——**不是模型随机，是多源指令在拉扯**。

另：`CLI建库要点.md:105-118` 坑11——`chapters.outline` 与 `outline_nodes.summary` 双口径注入，
混合施工图会直接长出错误情节（正文凭空多出护身符）。

### 根因 5：人物卡与上下文注入的是「档案」，不是「戏」

**证据**
- 角色注入字段：姓名/性格/说话风格/外貌/背景/动机/弧光/状态（`writer.py:112-128`）——
  **无「本章他要什么 / 怕失去什么 / 与谁的利益冲突」**。
- 出场勾选与 cast_constraint 管「谁能出现」，不管「谁在争什么」。
- 伏笔全态注入、因果链、信息边界、时序真相——一致性极强，**戏剧张力极弱**。
- 盲审沉淀反复要求却默认 prompt 没有：女主自主目标（`:27,107`）、配角独立算盘（`:36`）、
  主角可被数字/时限衡量的目标（`:70`）。

**机制**：模型拿到「谁」和「不能怎样」，缺「这场谁赢谁输、代价是什么」。
结果是关系戏靠梗、能力戏靠展示、冲突靠误会，**目标感靠事后特别指示补**。

### 根因 6：盲审人格与重写实验设计，强化「去 AI」弱于「造戏」

**证据**
- 阎浮 system 直接写「过不了腾讯朱雀检测……你就直接毙掉」（`blind_review.py:65,83`）——
  **市场编辑被检测器人格污染**。
- 重写禁改情节（`blind_review.py:166-168`）。
- 零上下文盲审铁律正确（审纸面），但产品把「纸面好句子」误当「整章好看」的充分条件。
- 校准结论已指出朱雀「不确定桶」= 既无人类特征也无 AI 特征的「第三种文体」
  （`ai-tone-research.md:142`）——**过度合规文本可能无聊**。

## 四、矛盾解释：「去 AI 味做了很多，为什么仍不好看」

1. **优化目标错位**  
   去 AI 味系统优化：困惑度/构式指纹/禁词/句长波动 → 人味分、朱雀率。  
   「好看」优化：开场问题、本章目标、阻碍强度、对白信息差、场景结果变化、章尾代价钩。  
   **两套指标几乎正交。** 高人味分只说明「不太像检测器里的 AI」，不说明「读者会追」。

2. **减法饱和，加法不足**  
   词表与构式禁令已较完整（deai_patterns、L0/L2、ai_metric 十余项）；  
   朱雀从 80%→44%→6.61% 的路径证明**禁令管统计指纹有效**。  
   但调研与词库反复强调：**正向特征（材料密度、情绪态度、不确定、场景摩擦、目标兑现）禁令产生不了**。  
   系统里正向戏剧层仍薄（事件清单一段 + 大纲钩子字段 + 用户特别指示）。

3. **「干净」文本的新无聊**  
   禁掉金句、禁掉升华、禁掉直接情绪、又要求留白与物证 → 模型收敛到  
   **匀速、克制、细节正确、冲突偏软** 的「第三种文体」。  
   盲审会一边骂 AI 腔，一边骂「讲得平淡，不知道在说什么」——两者可以同时真。

4. **事后收敛改不了骨架**  
   `tone_convergence` 只重写「怎么说」，保护「说什么」；盲审重写禁改情节。  
   若首稿就没有「他要什么 + 谁拦他」，再收敛也只是**更人味的平淡**。

5. **监督成本被特别指示吸收**  
   `writing_directives.md` 与龙族大纲证明：当人把「目标/代价/验证/钩子/禁 info dump」  
   写进 `user_directive` 或手写大纲时，质量显著上升。  
   这是**人工戏剧层在补系统缺口**，不是默认流水线已解决好看度。  
   放量时若不带 directive，「每章重犯」是文档自己写下的预言。

6. **门禁通过 ≠ 可读性通过**  
   日志 92–100 与盲审大量弃稿级意见并存；内部指标给用户虚假安全感。  
   产品审查亦指出人味分「无通过线无行动指引」。

## 五、优先改造建议（工作流 / prompt / 生成粒度，不是再加禁词）

### P0 — 生成粒度：长篇改为「节拍级施工」，对齐短篇节点

| 项 | 建议 |
|----|------|
| 拆锅 | 大纲【场景节拍】每拍单独一次 writer 调用（或 2 拍一包），单拍目标 400–800 字，再拼章。 |
| 每拍最小戏剧协议 | 调用前强制结构：`POV 要什么（可量化） / 谁或什么拦 / 本拍结果变化 / 留给下一拍的钩或代价`。可落进 outline 格式或 chapter_events 的 scene 级扩展。 |
| 续写轮纪律 | 续写 system 必须带：约束词库摘要 + 本拍未完成目标 + 禁止复述/禁升华；禁止「字数导向补写」。 |
| 验收 | 拼章后跑「场景完整性」启发式：每拍是否有对话或动作结果、是否有至少一次状态变化；失败不进人味门禁而直接标 `scene_thin`。 |

### P0 — Prompt 重构：戏剧指令升为 P0 模块，与 L0 同级

在约束词库新增 **`L1_writer_drama`（P0，永不裁剪）**，明确：
- 开场：第一行人声/动作/反常；前三行立「必须读下一句的问题」（把 `writing_directives` §一 进默认链路，而不是仅手册）。
- 本章一句话契约：`他要什么 + 谁拦他 + 不做成会失去什么`（写入手 system 与 outline 校验）。
- 对白：开口前算盘；禁止连续两轮通报式问答；同话题推拉 ≤2 回合必有推进。
- 能力戏：第三方验证；禁止作者替读者拆解谜底。
- 章尾：优先外部事件/倒计时/既成事实；禁止落在犹豫。
- 信息：身世与规矩禁止成段；一章至多一条，且必须挂在动作/道具上。

同时**下调**与之冲突的条目优先级或改写：
- 「每场景 ≥2 细节」改为「每场景 ≥1 个**推进剧情**的可核实细节，装饰细节 ≤1」。
- 江南遮蔽梯与「允许直写情绪」按题材 preset 互斥加载，禁止同时 P0。
- 技能包注入总量设硬顶（如 system 技能块 ≤800 字），防止审计已点名的「破万字豁免」。

### P1 — 门禁双轨：人味分之外增加「好看度」确定性代理指标

零 LLM 或低 LLM 成本即可上：
- **开场代理**：前 200 字是否含对话/动作动词/反常标记（禁纯景物）。
- **目标代理**：本章是否出现数字目标、时限、对赌、风险词（结合 chapter_events 是否非空）。
- **事件密度**：场景节拍落地检测（节拍句在正文中的覆盖/改写痕迹）；对白轮次中「试探空转」启发式。
- **钩子代理**：章末 150 字是否含外部名词事件（人到/车走/名单/倒计时/物品状态变化），而非心理动词。
- **盲审意见回写**：`verdict=弃稿` 的意见分类（钩子/空转/假情绪/info dump）写入 Reflexion，
  下一章 directive 自动生成「本章禁重犯」短清单（已有 reflexion 骨架，扩展分类即可）。

人味分继续保留，但 UI 文案必须拆开：
**「去AI味达标」≠「追读达标」**；好看度不达标时默认建议是**改大纲/加目标**，不是再收敛一次。

### P1 — 工作流：大纲与人物卡先补「戏」，再进正文

1. **大纲硬校验扩到戏剧字段**（现已有 7 字段格式）：  
   【核心事件】必须含「冲突/结果」动词；【场景节拍】必须含「冲突或动作」与「场面结果」；  
   【结尾钩子】禁止纯情绪句。不合规拒绝保存（与现有缺字段拒绝同机制）。
2. **人物卡增加「本章戏用」可选层**（或写作页出场勾选时填）：  
   `本章目标 / 与主角的利益关系 / 本章可展示的一次出手`。
3. **特别指示工业化**：把 `writing_directives.md` 蒸馏成可按体裁加载的 **drama directive 模板**  
   （都市日常 / 玄幻升级 / 同人），生成时自动注入，而不是依赖用户每次手贴。
4. **双大纲真源**：改大纲只走同步脚本/Web 同时写 `chapters.outline` 与 `outline_nodes.summary`  
   （产品侧：保存时双写，杜绝混合口径）。

### P2 — 评审闭环：盲审保留零上下文，另增「戏剧门」编辑

- 阎浮/白骨继续审纸面文笔与追读瞬间（现有设计正确）。
- 新增 **第三个可选编辑「结构执笔」**（或 Critic 扩展字段）：允许看大纲与事件清单，  
  只回答四件事：本章目标是否存在且可感？冲突是否升格？结果是否改变状态？钩子是否带代价？  
  ——**不看设定细节，只看戏剧语法**，避免重蹈旧 Keepers 全文审计。
- 重写策略分档：  
  - 文笔档：维持现盲审重写（不改情节）；  
  - 戏剧档：允许重写**改冲突强度与章尾**，人物/结局走向仍锁定（比现契约宽一档）。

### 明确不建议再做的事

- 继续堆 L3 禁词 / 更多正则去 AI——调研与校准已证明边际收益在戏剧层之外。
- 把人味分阈值从 90 调到 95 试图「更像人」——不解决追读。
- 依赖 tone_convergence / 盲审重写去修「没目标的章」——工具契约禁止改骨架。

## 七、结论一句话

**灵砚把「不像 AI」工业化了，但没有把「像一本让人追更的小说」工业化。**  
样稿材料足、句子常干净、人味分高；缺的是默认链路里的**节拍级场景施工 + 本章目标/冲突/代价协议 + 以追读为标的的门禁**。  
继续加禁词只会把文本推进「干净而无聊」的第三种文体；下一步应改**生成粒度与戏剧指令层**，并把 `writing_directives` 这类人工补丁收回为系统默认能力。
