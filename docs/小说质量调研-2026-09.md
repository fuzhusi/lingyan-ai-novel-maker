# 小说质量调研：怎么写出好小说（四路交叉，2026-09-30）

> 调研方式：四路并行（学术线 / 网文工业线 / 经典叙事学线 / 开源新项目线），互相独立的来源做交叉验证。
> 前置背景：灵砚已落地场景节拍拆锅、张力总线、双盲审、确定性门禁（开场钩/章尾钩/情绪峰值）、伏笔状态机、一致性链——本报告只讲**还缺什么**。

---

## 一、核心答案：好小说的五个公因子

四路独立来源收敛到同一组公因子，**每一项都可检测、可账本化**——这恰好印证灵砚「确定性优先」的路线：

### 1. 可信的人：愿望/需求双轨 + 对手网（Truby）
- 愿望（desire）= 意识到的具体目标，驱动情节；需求（need）= 无意识的性格缺陷修复，驱动转变。**只写愿望线则主题空转**。
- 对手网：不设单一反派，而是一组对手，**每个对手专攻主角弱点**并携带相竞争的价值观。
- 自揭示（结局的转变时刻）必须回答「需求」而非「愿望」——全书从此点倒推。

### 2. 递进的缺口：期望-结果裂缝（McKee）
- 场景 = 通过冲突的行动使至少一个**生活价值电荷翻转**（爱→恨、安全→危险）；首尾电荷相同即 nonevent，应删。
- Gap 机制：行动 → 世界反应异于预期 → 裂缝 → 迫使第二次更具风险的行动。渐进复杂 = 对抗力递增**且经过不可回退点**（escalation ≠ repetition）。
- 高潮 = 最大电荷、绝对不可逆的价值摆动；危机 = 不可逆的两难抉择。

### 3. 被管理的承诺：伏笔账本（Sanderson + autonovel）
- 承诺三分类：类型承诺（开局契约）/ 情节承诺 / 角色承诺；进度 = 「Yes, But / No, And」——成功带并发症、失败也推进信息。
- 第一定律：**任何 payoff 前必须有读者可验证的前置展示**（用魔法解冲突的能力 ∝ 读者对该魔法的理解度）。
- 回报标准：「必然且意外」。跨章管理 = promise→progress→payoff 状态机 + 每章增量校验（三章无增量报警）+ 传播债（上游改设定 → 下游未同步记账）。

### 4. 被调度的注意力：节奏参数（网文工业 + Swain）
- **断章四法**：章末必须断在「决定 / 发现 / 误判 / 代价」四类变化时刻，禁止总结式收尾；追读率八成取决于章末最后三五行。
- **爽点间距**：小爽点每 2000-3000 字一个（≈每章 1 个），大高潮每 2-3 万字一次，压抑期连续 ≤2 章。
- **Scene-Sequel 循环**：场景=目标-冲突-灾难，续章=反应-困境-决定——灾难强制反应、决定生成新目标，因果链永续。与断章四法独立来源交叉印证。
- **信息密度**：第一章前 300 字必须「人物+异常」可懂；每章要有「有用变化」计数。
- **毒点清单**：降智/送人头、圣母（放走反派不付代价）、长期虐主无反馈、注水。
- 钩子递进：沿「风险更具体、关系更贴身、选择更难撤回」推进；三章共享同一核心问题（入局→加压→承诺）。

### 5. 抗同质化：可预测性反制（学术实证）
- LLM 的可预测/同质化是**对齐训练的系统性偏差**（Creativity Has Left the Chat, ICLR 2024；Echoes in AI），不是偶发缺陷——必须生成端显式反制。
- 实证有效的两条路：**best-of-N + 故事专用奖励模型重排**（StoryReward, 2026）；多样新颖性信号（Multi-Novelty）。
- **LLM-judge 会系统性高估 AI 故事**（100-Endings, 2026）：rubric 打分把 AI 文排第一，而「逐句预测结局 100 次的猜不中率」能正确把 New Yorker 排在 AI 之上——**前瞻类指标比 rubric 可信**。
- 中文基准 WebNovelBench（2025）：把生成小说放进 4000+ 人类网文质量分布取百分位——比绝对分更有意义。

## 二、来源清单与要点

### 学术线（2024-2026）
- **最强长篇质量路线**：逐章计划 + 角色卡逐章状态跟踪 + 可验证奖励（GRPO）（arXiv 2503.22828，改编 CHIRON character sheets：3 主角 × 4 类信息 × 逐章更新），人类成对评审几乎全面胜过基线。
- 长度瓶颈已被 AgentWrite 式「带字数配额的子任务拆分」解决（LongWriter, ICLR 2025）；真正的失分点在**多约束遵循与连贯**（Suri, LIFEBENCH）。
- 角色一致性新基准：ConStory-Bench（特质/世界规则漂移）、Narrative State Tracking（training-free 状态跟踪）、Magnet（角色接地多智能体）。
- 情感弧线：全局六弧线分类不可靠，**场景级 Δvalence 与局部极值**才可靠（Elkins & Koch；MultiSentimentArcs）——低谷内允许局部正峰；悲剧=单调下行+假性上行；治愈文=低振幅高频微升无深谷。
- 起承转合对冲突万能论的修正：兴趣引擎是「转」（意外但合理的重新语境化），结=理解而非胜利；治愈系以节律与氛围替代对抗——**无冲突场景必须执行 recontextualize，否则为流水账**。

### 网文工业线
- 编辑只看前三章，审稿 3-5 分钟按印象分递进（跳舞/起点官方）；番茄 2 万字首签、每章 2000-2300 字、10 万字完读率 ≥10%（传统文）。
- 章节模板：爽点章 2000-2500 字情绪持续上升；打脸章 2500-3000 字先抑后扬。
- 大神流程：唐家三少日均 8000 字固定时段+存货保更新；卖报小郎君日更 8000、强融梗（「套路是表现爽的方式但非唯一方式」）。
- 高流失节点共识：前三章、上架/入V前后、大高潮后的过渡章。公开的逐章弃书数据**不存在**（平台内部报表）。
- 人设：男频=杀伐果断+道德底线灵活+不圣母；女频=人设鲜明度>正确性；反派忌工具人三段式（嚣张出场-狼狈打脸-无存在感退场），需动机自洽。

### 叙事学线
- 对话共识：每句台词是有意图的行动（tactic），人物极少直陈真意；on-the-nose（直陈潜台词）为首要故障——对应盲审抓到的「AI 字幕组」。
- Sanderson 三定律之首条已入上节；颠覆承诺时，替代路径满意度须 ≥ 原承诺。
- Scene & Sequel 微观 MRU：刺激→感受→本能→理性动作/言语，反应拍缺失则读者失联。

### 开源新项目线
- **autonovel（NousResearch）——本轮最大收获**：显式伏笔账本（大纲阶段生成 plant→payoff 义务）+ canon.md 硬事实库 + 角色注册表（Sanderson 能力滑条 + 弧光字段 wants/fears/change）；评估双层（机械 AI 腔词表 + LLM judge）+ 4 人格读者面板 + 章节间 Elo 对比 + 阈值线（底稿>7.5、连续 3 章低分触发暂停）+ **传播债**（上游修改后显式记账下游未同步章）。
- **CreAgentive（THU-KEG, ACL 2026）**：Story Prototype 类型无关知识图谱 + reward agent 打分驱动 refinement 循环（重写而非单次生成），$1/100 章。
- SillyTavern World Info：sticky（常驻）/cooldown（冷却）/delay（延迟）时间效应 + 递归激活——上下文注入的时间调度学。
- Dramatron（DeepMind，已开源）：节拍表只写「谁在哪做什么」不含台词，避免早期台词锁死后期；官方自批评「角色弧光公式化」。
- RecurrentGPT：段级「计划先行 + 可回改」，长程细节交检索不塞上下文。

## 四、优先级路线图

### P0（确定性门禁升级，零 LLM 成本，1-2 天）
1. **断章四法门禁**：章末 150-300 字命中「决定/发现/误判/代价」之一，禁总结收尾（可正则+小词表起步）
2. **爽点间距账本**：张力档×字数轴——每 2-3k 字 ≥1 个兑现拍、压抑连续 ≤2 章，超限进 Reflexion
3. **信息密度门禁**：第一章前 300 字「人物+异常」可懂检查；每章「有用变化」事件计数下限（chapter_events 已有事件计数，加阈值即可）
4. **钩子递进校验**：与上一章钩子对比，按「更具体/更贴身/更难撤回」维度单调性提示

### P1（结构层，1-2 周）
5. **角色状态回写闭环**：审批后 LLM 一次调用更新角色卡 status_json（want/fear/change/与主角关系现值）——逐章跟踪是学术实证最强杠杆，也是 ANG 采纳报告点名的头号缺口
6. **伏笔账本升级**：progress 增量字段+三章无增量报警+payoff 前置展示核验（雷同检测的 8-gram 思路复用：检查 payoff 章与前文埋设章的呼应）
7. **对手网+愿望/需求字段**：角色卡 schema 扩展+关系字段（攻击谁弱点）；细纲模板加「本章对手回合」

### P2（评估升级，2-4 周）
8. **盲审→读者面板**：2 人格扩 4 人格（+追更读者/拆书编辑）+ 两两 Elo + 阈值线（连续 3 章低分暂停并出整改清单）——直接吸收 autonovel
9. **可预测率测试**：便宜模型对「当前正文」采样 N 次预测下一章走向，测一致性（越一致越危险）——100-Endings 的低成本变体
10. **best-of-N 开关**：关键章生成 2 稿+盲审重排选优（成本×2 换质量，作者逐章决定）
11. **百分位自评**：定期把生成章混入网文样本集跑 WebNovelBench 式定位

### P3（上下文经济学）
12. **注入时间效应**：设定条目带 sticky/cooldown/delay，防读者疲劳也省 token
13. **传播债账本**：改设定后显式列出未同步的下游章
